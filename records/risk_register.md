# Risk Register

| 编号 | 风险 | 影响 | 预防措施 | 触发后的处理 |
|---|---|---|---|---|
| R01 | Dataset003_Liver 病例或标签缺失 | 数据无效 | 完整性检查和病例 ID 审计 | 停止训练并重新整理数据 |
| R02 | 图像和标签 shape、方向或标签值异常 | 指标失真 | 抽查原图与标签，记录方向和 spacing | 修复数据后重新预处理 |
| R03 | 不同模型使用不同 splits | 消融实验不公平 | 冻结 splits_final.json | 相关模型全部重训 |
| R04 | GPU 显存不足 | 训练中断 | Baseline 和模块显存预检 | 按预定义规则降低模块复杂度 |
| R05 | 云服务器实例被释放 | 日志和权重丢失 | 使用持久化磁盘并定期备份 | 从最近 checkpoint 恢复 |
| R06 | 不同运行使用不同代码版本 | 结果不可比较 | 每次记录 Git commit | 废弃不可追溯实验 |
| R07 | Fold 0 反复按 Dice 调参 | 产生选择偏倚 | Fold 0 只检查资源和稳定性 | 废弃受污染的确认性结果 |
| R08 | 磁盘空间不足 | 训练或预测失败 | 启动前检查剩余空间 | 扩容或归档后再继续 |
| R09 | 软件环境中途升级 | 实验条件不一致 | 冻结环境和依赖版本 | 在原环境重训受影响实验 |
| R10 | Transformer token 数过大 | 显存和速度异常 | 根据 nnUNetPlans 提前计算 token | 使用预定义轻量化回退方案 |
| R11 | checkpoint 无法重新加载 | 无法完成推理和复现 | 正式训练前做 reload 测试 | 停止正式实验并修复代码 |
| R12 | 训练出现 NaN 或 Inf | 实验失败 | 检查数据、AMP、学习率和模块输出 | 定位原因后重新执行 |
